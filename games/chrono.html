2045 크로노 스트라이커

2045 CHRONO STRIKER

미래의 날개로 과거의 전장을 가르다.

2045년의 미래 전투기가 1945년으로 시간 이동! 다섯 전장을 돌파하고 거대 보스와 맞서는 종스크롤 슈팅.

▶ 지금 플레이 ↗GitHub 소스 ↗

게임은 독립 사이트의 새 탭에서 열립니다.

CONCEPT ART · NOT A GAME SCREENSHOT

01 / THE STORY

어떤 게임인가요?

실험 전투기 XF-2045 Asterion이 시간 균열을 통과했습니다. 호송 해역부터 사막 최종요새까지 다섯 전장에서 살아남고 보급품으로 전력을 강화하세요.

02 / HOW TO PLAY

처음 시작하는 방법

  1. 01

    전투기 출격

    마우스나 드래그로 기체를 조종합니다. 총알은 자동 발사됩니다.

  2. 02

    보급품 확보

    파란 P로 화력을 강화하고 녹색 보급품을 활용합니다.

  3. 03

    최종 요새 돌파

    다섯 번째 사막 요새까지 연속 스테이지에 도전합니다.

03 / CONTROLS

조작 방법

PC 이동마우스 이동 또는 WASD / 방향키
폭탄마우스 왼쪽 클릭 또는 X / B
일시정지P / Esc
모바일기체 드래그 이동 · BOMB 버튼 · 일시정지 버튼

04 / TIPS

알아두면 좋은 팁

  • 폭탄은 적탄 제거와 광역 피해를 동시에 제공합니다.
  • 스테이지 후반에 보스가 등장하므로 생존과 보급에 집중하세요.

HIGHLIGHTS

이 게임의 매력

  • 자동 사격과 화력 업그레이드
  • 화면 전체를 타격하는 폭탄
  • 터치 드래그 방식 모바일 조종
