스킬 코어

SKILL CORE · AI QUALITY ARCADE

AI를 이해하는 가장 빠른 방법, 직접 플레이.

AI 심사품질 진단 과정을 33개의 가상 미션으로 익히는 교육 아케이드. 규칙·근거·검증을 직접 선택하세요.

▶ 지금 플레이 ↗GitHub 소스 ↗

게임은 독립 사이트의 새 탭에서 열립니다.

CONCEPT ART · NOT A GAME SCREENSHOT

01 / THE STORY

어떤 게임인가요?

스킬 지침에서 자료 조회, 판본 복원, OA·RD·RC 진단과 피드백까지 일곱 단계 시스템을 가상 미션으로 탐험합니다. 실제 특허 정보를 조회하거나 진단하는 서비스가 아닌 교육 게임입니다.

02 / HOW TO PLAY

처음 시작하는 방법

  1. 01

    게임 시스템 확인

    시스템 지도와 학습 도감으로 단계별 원리를 살펴봅니다.

  2. 02

    정확한 게이트 선택

    화면에 등장하는 3개 게이트 중 맞는 답을 스캔합니다.

  3. 03

    근거 확인

    미션 후 표시되는 관련 규칙과 해설로 판단을 점검합니다.

03 / CONTROLS

조작 방법

게이트 이동← / → 또는 A / D
스캔Space / Enter
게이트 바로 선택숫자 1 / 2 / 3
모바일게이트 카드 터치 또는 하단 ◀ · 스캔 · ▶ 버튼

04 / TIPS

알아두면 좋은 팁

  • 교육용 가상 사례이며 실제 법률 판단이나 특허 행정 시스템 호출은 수행하지 않습니다.
  • 판본 시점을 잘못 선택하면 근거가 달라질 수 있다는 점에 주의하세요.
